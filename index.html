Демо-проекты

Три концепта в разных стилях. Нажимайте, фильтруйте, переносите — всё работает в браузере. Это демонстрации, а не работы для реальных заказчиков.

Flowdesk

Приём заявок и записей для компании, которая обслуживает промышленное оборудование. Диспетчер видит все заявки на одной доске, клиент получает напоминание.

Функции: доска заявок, карточки клиентов, напоминания, уведомления в Telegram, статистика.

Стек: HTML, CSS, JS (демо); в боевой версии — Node.js, PostgreSQL, Telegram Bot API.

Telegram-лог: пока пусто

TenderTrace

Мониторинг закупок для поставщиков промышленного оборудования. Система оценивает, насколько закупка подходит вашему профилю.

Функции: поиск, фильтры, оценка релевантности, карточка закупки, аналитика по отраслям.

Стек: HTML, CSS, JS (демо); в боевой версии — Python-парсеры, API площадок, Postgres.

Frameport

Клиентский портал для фотографа: после съёмки клиент открывает свою галерею, отмечает любимые кадры и следит за ретушью.

Функции: галерея, избранное, статусы обработки, выдача материалов, история заказов.

Стек: HTML, CSS, JS (демо); в боевой версии — Next.js, объектное хранилище, подписанные ссылки.

Обо мне

Я независимый разработчик. Работаю один, поэтому вы общаетесь напрямую с тем, кто пишет код: без менеджеров-посредников и пересказов задачи.

Мне интересны задачи, где программа убирает повторяющуюся работу: заявки, учёт, уведомления, отчёты. Сначала разбираюсь, как устроен ваш процесс, и только потом выбираю технологии.

Пишу простой и поддерживаемый код, передаю исходники и описание, чтобы проект не зависел от меня.
